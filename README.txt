CRAVE HUB — GOLD PREMIUM FINAL

Files included:
- index.html: page structure
- style.css: premium burgundy, ivory and gold styling
- script.js: menu search, categories, favourites, cart, checkout and demo tracking
- assets/thamizh-portrait.png: portrait used on the first screen and small creator signature

GitHub Pages: upload the contents of this folder to the repository root. Keep index.html, style.css, script.js and the assets folder together.
